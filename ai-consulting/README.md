# AIコンサル ご相談ページ

自分あての「AIコンサルの依頼ページ」です。まだ公開していません。
ヘッダーのリンクから、ジャンルごとのページに移動できる作りです。

## ファイル構成

```
ai-consulting/
├── index.html        … トップページ（メイン画像＋ジャンル一覧）
├── web-design.html   … AI × Webデザイン
├── data.html         … AI × データ
├── automation.html   … AI × 業務効率化
├── marketing.html    … AI × マーケティング・SNS
├── writing.html      … AI × 文章・資料作成
├── training.html     … AI × 社内研修・活用サポート
├── style.css         … 見た目（全ページ共通）
├── script.js         … ヘッダーのリンク・フォーム・チャットの動き（全ページ共通）
└── images/           … 画像（hero.svg がトップ用、ほかは各ジャンル用の仮画像）
```

## よくある編集

### メイン画像を入れ替える
各ページの HTML に「▼▼▼ メイン画像はここ ▼▼▼」という目印があります。
1. 画像を `images/` に入れる（例: `images/data.jpg`）
2. 目印の下の `src="images/data.svg"` を `src="images/data.jpg"` に変える
3. `alt="..."` を画像の内容に合わせて変える

### ページの文章を変える
そのジャンルの HTML ファイル（例：`data.html`）を開いて、文章を直接書き換えます。

### ジャンル（AI×〇〇）を増やす
1. 既存のジャンルページ（例：`data.html`）をコピーして、新しい名前にする（例：`ai-video.html`）
2. コピーしたファイルの `<body data-genre="data">` を新しい id（例：`ai-video`）に変え、文章と画像を書き換える
3. `script.js` の `GENRES` に `{ ... }` を1つ追加する
   → ヘッダーのリンクとトップページのカードは自動で増えます
4. （任意）`script.js` の `CHAT_FAQ` に、そのジャンルのチャット回答を追加する

### チャットの回答を変える
`script.js` の `CHAT_FAQ`。ジャンルごとの回答と、`common`（全ページ共通）があります。
`keys` は「この言葉が質問に含まれていたらこの回答を返す」というキーワードです。

### 色を変える
`style.css` の一番上の `--color-main` などを変えます。

## 公開する前にやること
- **フォームの送信先を設定する**：今は `script.js` の `CONFIG.FORM_ENDPOINT` が空なので「デモモード」です（入力しても誰にも届きません）。
  Formspree などのフォーム受付サービスのURLを入れると、実際に送信されるようになります。
- チャットボットは「用意した回答を返す」仕組みで、AI（ChatGPTなど）にはつながっていません。
- 料金・流れなど、チャットの回答文が実際の内容と合っているか確認する。
