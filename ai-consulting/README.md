# AIコンサル ご相談ページ

自分あての「AIコンサルの依頼ページ」です。まだ公開していません。

## ファイル構成

```
ai-consulting/
├── index.html   … ページの骨組み（メイン画像の場所もここ）
├── style.css    … 見た目（色・レイアウト）
├── script.js    … ジャンルの内容・チャットの回答・フォームの動き
└── images/
    └── hero.svg … 仮のメイン画像
```

## よくある編集

### メイン画像を入れ替える
1. 画像を `images/` に入れる（例: `images/hero.jpg`）
2. `index.html` の「▼▼▼ メイン画像はここ ▼▼▼」の下の `src="images/hero.svg"` を `src="images/hero.jpg"` に変える
3. `alt="..."` を画像の内容に合わせて変える

### ジャンル（AI×〇〇）を増やす・変える
`script.js` の `GENRES` の中の `{ ... }` のかたまりを1つコピーして、内容を書き換えます。
ヘッダーのメニューとカードは自動で増えます。

### チャットの回答を変える
- ジャンルごとの回答：`GENRES` の各ジャンルの `faq`
- 全ジャンル共通の回答：`COMMON_FAQ`
- `keys` は「この言葉が質問に含まれていたらこの回答を返す」というキーワードです。

### 色を変える
`style.css` の一番上の `--color-main` などを変えます。

## 公開する前にやること
- **フォームの送信先を設定する**：今は `script.js` の `CONFIG.FORM_ENDPOINT` が空なので「デモモード」です（入力しても誰にも届きません）。
  Formspree などのフォーム受付サービスのURLを入れると、実際に送信されるようになります。
- チャットボットは「用意した回答を返す」仕組みで、AI（ChatGPTなど）にはつながっていません。
- 料金・流れなど、チャットの回答文が実際の内容と合っているか確認する。

## 確認のしかた
`index.html` をブラウザで開くだけで表示できます。
