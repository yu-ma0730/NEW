# SNS運用ナビ

SNSマーケティングを **5つのステップ** で、くり返し回すための、ブラウザだけで動くツールです（インストール・サーバー不要）。

画面上部で使い方を切り替えられます。

- **自社の商品・お店を広める**：商品がある → 買いそうな人と場所を決める → 投稿 → 振り返り
- **アフィリエイトで紹介する**：悩みを持つ人を先に見つける → ASPから合う商品を選ぶ → 投稿 → 振り返り。商品の中身・価格・販売ページは変えられないため、動かせる「誰に」「どう伝えるか」「どの商品を選ぶか」の3つだけを扱います

| ステップ | できること |
|---|---|
| 1. 市場調査 | キーワードから X・Yahoo!リアルタイム検索・Googleトレンド・TikTok Creative Center・Instagram・YouTube・Threads のトレンド／検索画面へのリンクを作成。見つけたトレンドを「関連・勢い・作りやすさ・リスク」で評価して「乗る／様子見／見送る」を判定し、そのまま投稿のテーマに使える。claude.ai 上で開いた場合は、Claude に投稿の切り口を相談できる |
| 2. 戦略 | アフィリエイトでは、狙う悩みに合うASPの案件を3つまで比べ（悩みとの一致・報酬・承認率・EPC・SNS掲載の可否）、まず1周する「商品A」を選ぶ。以下は共通： | 業種・目的・ターゲット年代・素材・作業時間から、相性の良いSNSをランキング。KGI/KPI と「投稿の4つの柱（教育・共感・信頼・行動）」の配分を提案 |
| 3. 投稿計画 | 柱の配分に沿った4週間の投稿カレンダーを自動作成。表計算ソフトに貼れる形でコピー可能 |
| 4. 投稿づくり | 「問いかけ型」「数字型」「結論先出し型」の3つの書き出しで下書きを作成。SNSごとの文字数上限（Xは全角=2で計算）とハッシュタグ数の目安つき。企業から依頼・商品提供を受けた投稿には冒頭に【PR】と依頼元を自動で入れ（ステマ規制対応）、「No.1」「必ず」「半額」など景品表示法で注意が必要な表現を警告 |
| 5. 振り返り | インサイトの数字からエンゲージメント率・保存率・シェア率・クリック率・フォロワー増加率など・成果率を計算し、判定と「次にやること」を表示。1つを「今月のテーマ」にすると戦略シートに反映される。月ごとに結果と「変えたこと」を記録し、前回比を表示。アフィリエイトでは、クリック率と成果率から「誰に・どう伝えるか」と「どの商品か」のどちらを動かすかを示す |

## 使い方

`index.html` をブラウザで開くだけです。最初はカフェの入力例が入っています。
入力内容はそのブラウザの localStorage にだけ保存され、外部には送信されません。

## 注意

トレンドのデータはツールが自動で取得するのではなく、リンク先の公式画面で確認する方式です（X API などは有料で、各SNSの規約上スクレイピングもできないため）。


広告表示と表現のチェックは、うっかりミスを防ぐための補助です。法的な判断を保証するものではないため、迷う場合は消費者庁のガイドラインや専門家に確認してください。


相性スコアや判定の基準値は一般的な傾向にもとづく目安です。SNSやジャンル、アカウント規模で差が大きいため、他社比較より「先月の自分」との比較に使ってください。
