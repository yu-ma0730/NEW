# SNS運用ナビ

SNSマーケティングを **4つのステップ** で進めるための、ブラウザだけで動くツールです（インストール・サーバー不要）。

| ステップ | できること |
|---|---|
| 1. 戦略を決める | 業種・目的・ターゲット年代・素材・作業時間から、相性の良いSNSをランキング。KGI/KPI と「投稿の4つの柱（教育・共感・信頼・行動）」の配分を提案 |
| 2. 投稿計画 | 柱の配分に沿った4週間の投稿カレンダーを自動作成。表計算ソフトに貼れる形でコピー可能 |
| 3. 投稿づくり | 「問いかけ型」「数字型」「結論先出し型」の3つの書き出しで下書きを作成。SNSごとの文字数上限（Xは全角=2で計算）とハッシュタグ数の目安つき。企業から依頼・商品提供を受けた投稿には冒頭に【PR】と依頼元を自動で入れ（ステマ規制対応）、「No.1」「必ず」「半額」など景品表示法で注意が必要な表現を警告 |
| 4. 分析・改善 | インサイトの数字からエンゲージメント率・保存率・シェア率・クリック率・フォロワー増加率などを計算し、判定と「次にやること」を表示 |

## 使い方

`index.html` をブラウザで開くだけです。最初はカフェの入力例が入っています。
入力内容はそのブラウザの localStorage にだけ保存され、外部には送信されません。

## 注意

広告表示と表現のチェックは、うっかりミスを防ぐための補助です。法的な判断を保証するものではないため、迷う場合は消費者庁のガイドラインや専門家に確認してください。


相性スコアや判定の基準値は一般的な傾向にもとづく目安です。SNSやジャンル、アカウント規模で差が大きいため、他社比較より「先月の自分」との比較に使ってください。
