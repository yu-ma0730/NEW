SNS運用ナビ

SNS運用を「市場調査 → 戦略 → 投稿計画 → 投稿づくり → 振り返り」の5ステップで、くり返し回すためのツールです。入力はすべてこのブラウザ内だけで処理されます。最初は例が入っています。

調べるテーマ

キーワードを入れると、各SNSのトレンド・検索画面へのリンクができます。

商品名・ジャンル・お客様が悩みを話すときの言葉など。
リンク先で気になった話題・ハッシュタグ・音源名を書き留めてください。右側で「乗るか・見送るか」を判定します。

最初に入っているのはカフェの例です。トレンドの評価も例として付けています。

Claudeに切り口を相談

「乗る」「様子見」のトレンドと、戦略ステップの業種・目的・ターゲットをもとに、投稿の切り口を提案します。Claudeはここからネットを見に行けないため、トレンドの中身は上で調べた内容を使います。

週1回・15分の調査ルーティン

  1. 悩みの生の声を集めるYahoo!知恵袋やSNSの検索で「〇〇 不安」「〇〇 どうすれば」を調べ、使われている言葉をそのままメモする。
  2. 悩んでいる人の多さを確かめるGoogleトレンドで検索数の推移を見る。回答や反応が多い質問も、悩んでいる人が多いサイン。
  3. レビューで「足りない点」を知る通販サイトで星2〜3のレビューを読む。紹介するときに正直に伝えるべき点が分かる。
  4. 合う商品をASPで探すA8.netなどで悩みの言葉から案件を探し、報酬・承認率・提携条件（SNSに載せてよいか）を確認する。
  5. 1つに決めて投稿する「狙う」になった悩みを1つ選び、戦略ステップで商品を1つに絞って投稿する。
  1. 今の話題をつかむXのトレンドと Yahoo!リアルタイム検索で、今週よく話されている言葉を見る。
  2. 伸びているか確かめるGoogleトレンドで検索数が上がっているか、毎年同じ時期に来る季節ネタかを確認する。
  3. 動画の流行を見るTikTok Creative Center で伸びているハッシュタグと音源を見る。ビジネスアカウントは商用利用できる音源しか使えないので注意。
  4. 競合を見る同業のアカウント3つで、直近1か月に反応が多かった投稿の形式とテーマをメモする。
  5. 判定して1つ投稿する左に書き出して評価し、「乗る」になったものを今週の投稿にする。

災害・事件・訃報など、困っている人がいる話題には便乗しないでください。炎上の原因になります。

ASPで提携する前のチェック
  • プログラムの提携条件で、使うSNSに載せてよいか（媒体ごとに可否が違うことがある）
  • SNSアカウントを「媒体（サイト）」としてASPに登録したか
  • 広告主が決めている表現のルール・NGワードを確認したか
  • 自分で申し込んで報酬を得る「自己アフィリエイト」は、許可された案件以外でしない
  • 投稿には【PR】などの広告表示を入れる（アフィリエイトもステマ規制の対象）

商品の中身・価格・販売ページは変えられません。動かせるのは「誰に」「どう伝えるか」「どの商品を選ぶか」の3つです。
