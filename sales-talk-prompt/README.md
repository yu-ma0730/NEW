# セールストーク生成プロンプト

画像またはテキストから、クオリティ（ペルソナ）を選んでセールストークを作るプロンプトです。
文字数制限のある別プロンプト・別システムに組み込む前提で、**変数で差し替えでき、出力はJSON** になっています。

| ファイル | 内容 |
|---|---|
| `SALES_TALK_PROMPT.md` | プロンプト本体（`PROMPT START`〜`END` をコピーして使う） |
| `validate.py` | 出力JSONの文字数・要確認ワードをチェックするスクリプト |
| `sample_output.json` | `validate.py` の動作確認用サンプル（NG例を含む） |
| `THREADS_A8_PROMPT.md` | Threads投稿用（4人×3案・A8.net・PR表記対応）。下の「変数」を埋めて丸ごと貼る |
| `counter.html` | Threads 投稿メーカー。各欄に文字数カウンター付き。欄を埋めるとクオリティ4人（Lv1〜4）全員分のプロンプトができ、仕上げチェックで投稿の文字数・改行・PR表記・NG候補を確認 |

| Lv | ペルソナ | 特徴 |

## 呼び出し例（別プロンプトへの組み込み）

```
<SALES_TALK_PROMPT.md の PROMPT START〜END>

---
QUALITY: 2
INPUT_TYPE: image
PRODUCT_INFO: 全自動コーヒーメーカー。価格12,800円（税込）。豆から挽ける。
EXPERIENCE: なし
IS_PAID: はい
TARGET: 30代の共働き夫婦
CHANNEL: SNS投稿
CHAR_LIMITS:
  catch: 20
  body: 60
  closing: 40
  total: 200
（画像を添付）
```

出力されたJSONは `python validate.py output.json` でチェックし、`NG` が出たら再生成させてください。
AIは日本語の文字数を数え間違えることがあるので、**文字数の最終判定は必ずプログラム側で** 行う設計にしています。

## Threads投稿の流れ
1. `counter.html` に商品の画像・テキスト（ASPのプログラム詳細、Amazonの商品ページなど）を貼って「読み込んで欄に入れる」→ 欄を確認して手で直す → 「全体のプロンプト」「変数のプロンプト」をコピーしてAIに貼る。手で書くなら `THREADS_A8_PROMPT.md` の「変数」を埋める
2. 4人×3案（最大12案）が出て、1案ごとに採点とメンバー本人のプレゼン（おすすめポイント3つ）、最後に総合ランキングが付く
3. 選んだ案を `counter.html` に貼り、赤（×・NG候補）がなくなるまで手で直す
4. 本文を投稿 → A8.netのリンクは「リンク用ツリー投稿」で自分への返信として投稿

## 注意
- コンプライアンス条項はAIへの指示であり、法的チェックの代わりにはなりません。広告として公開する前に、人の目で確認してください（特に化粧品・健康食品・金融）。
- `validate.py` のNGワードは簡易リストです。扱う商材に合わせて追加してください。
