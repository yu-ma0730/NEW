# ハイトレ式 環境認識×2波サイン（TradingView インジケーター）

YouTube「ハイトレFX 億トレーダーへの道」で解説されている考え方
（**上位足の環境認識 → ダウ理論の転換 → エリオット波動の1波・2波を見極めて3波を取る**）を、
TradingView の Pine Script v6 でサインツールにしたものです。

> ⚠️ これは **非公式の再現版** です。ハイトレFXさん本人のルールを完全に再現したものではありません。
> 公開されている情報をもとに、機械的に判定できる形へ置き換えています。
> 実際に使う前に、必ず過去検証とデモ口座でのフォワードテストをしてください。

## 導入方法

1. TradingView でチャートを開き、下部の「Pine エディタ」を開く
2. `haitore_signal.pine` の中身をすべて貼り付ける
3. 「保存」→「チャートに追加」
4. 推奨の組み合わせ：**執行足 5分 or 15分**／上位足A **4時間**／上位足B **1時間**

## ロジック

### ① 環境認識（上位足A・B・執行足）

| 項目 | 判定 |
|---|---|
| ダウ | 直近スイング高値を終値で上抜け→上昇／直近スイング安値を下抜け→下降 |
| MA | SMA20 の向き（上向き・下向き・横ばい） |
| 判定 | ダウが上昇 **かつ** 終値がSMA20より上 → 上昇／逆なら下降／それ以外はレンジ・調整 |
| 水平線 | 上位足の直近スイング高値・安値をチャートに線で表示 |

上位足は **確定足のみ** で判定するため、リペイント（後から判定が変わること）は起きません。

右上のパネルに各時間足の状態と **総合目線** を表示します。

- 上位足A・Bがどちらも上昇 → 買い目線
- 上位足Aが上昇でBが調整中 → 押し目待ち（まだ入らない）
- 方向がそろわない → 様子見

### ② エントリー（執行足）

1. **仮1波**：最後の戻り高値（下降中のスイング高値）を終値で上抜けた波を1波とみなす
   - 下降から上昇に変わった場合は「転換型」、上昇が続いている場合は「継続型（押し目）」と表示
2. **2波**：1波の 38.2% 以上押したら、チャートに押し目ゾーン（38.2〜78.6%）を塗りつぶして表示
   - 78.6% より深く押したら、1波ではなかったと判断して取り消す
3. **反転確認**：ゾーン内で直近3本の高値を終値で上抜けたら **BUY サイン**（確定足のみ）
4. **フィルター**：次の場合はサインを出さず、灰色の × を表示する
   - 上位足の目線と逆
   - 上位足の水平線までの余地が 1R 未満
   - リスクリワードが 1.5 未満

売りはこの逆の手順です。

### ③ 損切り・利確

| | 位置 |
|---|---|
| 損切り | 2波の先端（または1波の始点）から ATR×0.2 外側 |
| TP1 | 1波の先端（ここで半分利確・建値移動といった使い方を想定） |
| TP2 | 2波の先端 + 1波の値幅 × 1.618（3波の目標） |

サインが出ると、ラベルで Entry／SL／TP1／TP2／RR を表示し、SL・TP のラインを引きます。

## アラート

- 「アラート作成」→ 条件で `HT Signal` を選ぶ
- `HT 買いサイン` / `HT 売りサイン`：シンプルな通知
- 「alert() 関数の呼び出しのみ」を選ぶと、Entry／SL／TP の価格も通知に含まれます

## 主なパラメーター

| パラメーター | 初期値 | 説明 |
|---|---|---|
| 上位足A / B | 240 / 60 | 環境認識に使う時間足 |
| 上位足フィルター | 両方一致 | `上位足Bのみ` や `逆行しなければOK` にするとサインが増える |
| 執行足のスイング判定本数 | 3 | 大きくするほど大きな波だけを1波として拾う |
| 2波 押し戻しの上限・下限 | 0.382 / 0.786 | 押し目ゾーンの範囲 |
| 1波の最小サイズ | ATR×1.0 | 小さすぎる波を無視する |
| 最低RR | 1.5 | TP2 を基準にしたリスクリワード |

## 注意点

- 波の数え方（どこを1波とするか）は裁量の部分が大きいです。このツールは「戻り高値抜け＝仮1波」と機械的に決めています。
- 重要指標の発表前後、レンジ相場、上位足の水平線の真下・真上では、ダマシが増えます。
- サインは判断の補助です。エントリーの根拠は、必ずご自身のチャートでも確認してください。
