# 📅 自動投稿スケジューラー

1週間／1か月の予定表で日付を選び、**どこに（X・Threads・ブログ）**・**いつ**投稿するかを予約すると、その時間に自動で投稿するツールです。
Python 標準ライブラリだけで動くので、`pip install` は不要です。

## 使い方

```bash
cd auto-poster
cp .env.example .env     # 最初は DRY_RUN=1 のまま（実際には投稿されない）
python3 app.py
```

ブラウザで http://127.0.0.1:8000 を開きます。

1. **どこに・何を？** 投稿先のタブ（X / Threads / ブログ）を切り替えて、それぞれの形式で内容を作る
   - **Threads**：アプリと同じ並び。トピックを付けて、「スレッドに追加」で 1/2・2/2… と連投
   - **X**：ポストごとに残り文字数の円ゲージ。「＋ ポストを追加」でスレッド（連投）
   - **ブログ**：記事タイトル＋本文
   - 「他の内容をコピー」で別の投稿先の文章を流用（X・Threads へは文字数上限で自動分割）
2. **いつ？** 予定表で日付をクリック（複数日まとめて選べる）
3. **時間** を設定して「予約する」

予約一覧から **取消**・**今すぐ投稿** ができます。投稿結果（成功／失敗理由）も一覧に残ります。

## アカウントのログイン（アカウント連携）

画面右上の **🔑 アカウント連携**（または投稿タブ内の「ログインする」）から、投稿するアカウントにログインします。
ログイン情報はこの PC の `data/accounts.json` にだけ保存されます（共有・コミットしないこと）。

| 投稿先 | ログイン方法 | 事前に必要なもの |
|---|---|---|
| X | 「𝕏 でログイン」→ X の画面で許可 | developer.x.com のアプリ（Read and write / Web App）の Client ID・Secret。Callback URI は画面に表示される URL を登録 |
| Threads | 「Threads でログイン」または **アクセストークンを貼り付け** | Meta for Developers の Threads アプリ。Meta は https のリダイレクト URL しか登録できないため、PC だけで使うなら貼り付けが簡単 |
| ブログ | サイト URL・ユーザー名・アプリケーションパスワードを入力 → 接続テスト | WordPress の「プロフィール → アプリケーションパスワード」 |

- X のトークン（2時間）・Threads のトークン（60日）は投稿前に自動で更新します。
- ブラウザで開くのは `http://127.0.0.1:8000` にしてください（X は `localhost` のコールバックを受け付けません）。
- サーバーを https で公開する場合は `.env` の `PUBLIC_URL` にその URL を設定すると、コールバック URL がそれに変わります。

最後に `.env` の `DRY_RUN=0` にして再起動すると、実際に投稿されます。

## .env で設定する方法（従来どおり）

ログインの代わりに `.env` に認証情報を書いても動きます（ログインした情報が優先されます）。

| 投稿先 | 必要なもの | 使っている API |
|---|---|---|
| X | API Key/Secret, Access Token/Secret（Read and write 権限） | `POST /2/tweets`（OAuth 1.0a） |
| Threads | アクセストークン | Threads Graph API（作成 → 公開） |
| ブログ | WordPress の URL・ユーザー名・アプリケーションパスワード | WP REST API `/wp-json/wp/v2/posts` |

## 注意

- **PC（サーバー）が起動している間だけ**投稿されます。止まっていた間に過ぎた予約は、次回起動時にまとめて投稿されます。
- 画面にログイン機能はありません。初期設定では自分の PC（127.0.0.1）からのみアクセスできます。外部公開する場合は認証を追加してください。
- X API は有料プランでないと投稿数に制限があります。最新の料金・制限は公式で確認してください。
- 予約データは `data/posts.json` に保存されます。
