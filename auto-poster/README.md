# 📅 自動投稿スケジューラー

1週間／1か月の予定表で日付を選び、**どこに（X・Threads・ブログ）**・**いつ**投稿するかを予約すると、その時間に自動で投稿するツールです。
Python 標準ライブラリだけで動くので、`pip install` は不要です。

## 使い方

```bash
cd auto-poster
cp .env.example .env     # 最初は DRY_RUN=1 のまま（実際には投稿されない）
python3 app.py
```

ブラウザで http://127.0.0.1:8000 を開きます。

1. **どこに・何を？** 投稿先のタブ（X / Threads / ブログ）を切り替えて、それぞれの形式で内容を作る
   - **Threads**：アプリと同じ並び。トピックを付けて、「スレッドに追加」で 1/2・2/2… と連投
   - **X**：ポストごとに残り文字数の円ゲージ。「＋ ポストを追加」でスレッド（連投）
   - **ブログ**：記事タイトル＋本文
   - 「他の内容をコピー」で別の投稿先の文章を流用（X・Threads へは文字数上限で自動分割）
2. **いつ？** 予定表で日付をクリック（複数日まとめて選べる）
3. **時間** を設定して「予約する」

予約一覧から **取消**・**今すぐ投稿** ができます。投稿結果（成功／失敗理由）も一覧に残ります。

## 本番投稿の設定

`.env` に各サービスの認証情報を入れ、`DRY_RUN=0` にして再起動します。画面上部のバッジで「接続済／未設定」を確認できます。

| 投稿先 | 必要なもの | 使っている API |
|---|---|---|
| X | API Key/Secret, Access Token/Secret（Read and write 権限） | `POST /2/tweets`（OAuth 1.0a） |
| Threads | アクセストークン | Threads Graph API（作成 → 公開） |
| ブログ | WordPress の URL・ユーザー名・アプリケーションパスワード | WP REST API `/wp-json/wp/v2/posts` |

## 注意

- **PC（サーバー）が起動している間だけ**投稿されます。止まっていた間に過ぎた予約は、次回起動時にまとめて投稿されます。
- 画面にログイン機能はありません。初期設定では自分の PC（127.0.0.1）からのみアクセスできます。外部公開する場合は認証を追加してください。
- X API は有料プランでないと投稿数に制限があります。最新の料金・制限は公式で確認してください。
- 予約データは `data/posts.json` に保存されます。
