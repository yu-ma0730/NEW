# Self OS — 自分をマネジメントするツール

[Addness](https://addness.co.jp/) の考え方（目的 → ゴール → ToDo への分解、今やることへの集中）を参考にした、個人用セルフマネジメントWebアプリです。
`index.html` 1ファイルだけで動きます（ビルド不要・サーバー不要）。

## 使い方（2通り）
1. **claude.ai のページとして使う**：公開済みのページを開く。サインインしていればデータはクラウドに保存され、APIキーなしでAIが使えます。
2. **普通のWebサイトとして使う**：`index.html` をブラウザで開くか、GitHub Pages / Vercel などに置く。データはそのブラウザに保存されます。
   - GitHub Pages の例：リポジトリの Settings → Pages → Branch を選んで保存すると `https://yu-ma0730.github.io/NEW/self-manager/` で開けます。

同じ `index.html` が、開かれた場所を見分けて動作を切り替えます。

## 機能
| 画面 | 内容 |
|---|---|
| 今日 | **Focus ToDo**：いまやるべきToDoを1つだけ表示（今日の予定 → 期限切れ → 期限が近い順）。**Daily Focus**：今日やる3つを手動か自動で選ぶ。完了数と連続達成日数も表示 |
| ゴールツリー | 目的・ゴール・ToDoを階層で管理し、進捗率を自動計算。「分解」ボタンで中間ゴールとToDoを生成 |
| 壁打ち・振り返り | AIとの相談（APIキーがある場合）か、自問用の問いリスト。毎日の振り返り（できたこと／詰まったこと／明日の一手）を書き、「一手」を翌日のToDoにする |
| 設定 | 保存先の表示、APIキー（通常サイト版のみ・任意）、バックアップ（ファイル書き出し／コピー／読み込み）、例のデータ |
| ヘルプ・お問い合わせ | よくある困りごと、状態チェック（保存先・AI・件数）、問題の報告フォーム（GitHub Issue 作成画面を報告文入りで開く／報告文コピー） |

## 問い合わせ窓口
アプリ内の「ヘルプ・お問い合わせ」から報告すると、このリポジトリの [Issues](https://github.com/yu-ma0730/NEW/issues) に届きます。報告文にはアプリの状態（保存先・AIの状態・件数・ブラウザ）が自動で付き、ゴールやToDoの中身は含まれません。

## AI について
- claude.ai のページでは、ページのAI機能を使います（APIキー不要・初回に許可画面が出ることがあります）。
- 通常のWebサイトでAPIキーがない場合、「分解」は汎用テンプレート（現状把握 → 最初の一歩 → 継続と振り返り）で動きます。
- APIキーを設定すると、「分解」と「壁打ち」がブラウザから直接 Claude API（`api.anthropic.com`）を呼び出します。キーはそのブラウザの localStorage にだけ保存されます。共有PCでは使わないでください。

## データ
- claude.ai のページ：サインインして書き込める人は、本人だけが読めるクラウド領域に保存（他の閲覧者からは見えません）。それ以外はブラウザ内。
- 通常のWebサイト：ブラウザの localStorage（`selfos.v1`）。端末を移るときは書き出し／読み込みを使ってください。
