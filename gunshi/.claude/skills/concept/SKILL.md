# コンセプトメイク

`brief.md` と `knowledge/frameworks.md`（第1章・第5章）を読んでから始める。brief.md が無ければ `/hearing` を案内して止まる。

## 手順

### 1. 現状診断（短く）
- **市場の成熟度**：第1〜5段階のどこか、理由1行
- **主な顧客の認識度**：無自覚／問題に気づいている／解決策を探している／商品を比較中／購入直前
- **飢えた群衆**：今すぐ欲しがっている人は誰で、どこにいるか

### 2. 欲求の特定
LF8・9つの後天的欲求・日本版購買動機から、この顧客に効く上位3つを選び、brief の顧客の言葉で根拠を示す。

### 3. ポジショニング案を3つ
それぞれ以下の形式で：
```
【案A：〇〇特化型】
・誰の：
・どんな悩みを：
・どう解決する：
・競合との違い：
・「〇〇といえば」：
・リスク／弱点：
```
3案は **方向性を変える**（例：専門特化／新カテゴリ創造／価値観・想い訴求）。

### 4. ビッグアイデア（各案1つ、15字以内）

### 5. キャッチコピー案（各案3本 ＝ 計9本）
- 4Uの法則で各コピーを ◎○△ で自己採点
- 日本語として自然か、声に出して読んで違和感がないかを確認
- 誇張表現・根拠のない最上級は使わない

### 6. 軍師の推奨
3案のうち1つを推し、理由を3行で。**「この案の弱点」も正直に書く。**

最後に `output/YYYYMMDD_concept_<テーマ>.md` に保存し、次は `/lp` か `/sns` を案内する。
