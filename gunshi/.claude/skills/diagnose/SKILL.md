# 数字診断（アフィリエイト・発信者向け）

`profile.md`（無ければ `brief.md`）を読む。どちらも無ければ `/hearing` を案内するが、数字が貼られていれば診断は先に進めてよい。

## 1. 数字を整理する
貼られた数字やスクショから、以下の表に整理する。分からない欄は「不明」とし、推測で埋めない。

| 段階 | 数字 | 率 |
|---|---|---|
| 見られた（PV・インプレッション） | | |
| クリックされた | | クリック率 = クリック ÷ 表示 |
| 発生（申込・購入） | | CVR = 発生 ÷ クリック |
| 確定（承認） | | 承認率 = 確定 ÷ 発生 |

**A8.net の注意**：「インプレッション」はバナー広告の表示回数で、テキストリンクは数えないことが多い。インプレッションよりクリックが多くても異常ではない。

## 2. 詰まっている場所を1つ特定する
| 症状 | 考えられる原因（多い順） | 確認すること |
|---|---|---|
| 見られていない | 集客不足、狙うキーワード・ハッシュタグがずれている | どの媒体から来ているか |
| 見られるがクリックされない | 紹介文が弱い、リンクの位置・文言、読者と案件が合っていない | リンク直前の文章 |
| **クリックされるが発生しない** | ①読者と案件のミスマッチ（興味本位のクリック）②成果条件が重い（本人確認・初回入金など）③リンク先LPと紹介文の期待がずれている ④スマホでリンク切れ・案件終了 ⑤自分のクリックが多く含まれている | どの記事・投稿のどのリンクか、案件の成果条件、実際にスマホで踏んでみる |
| 発生するが確定しない | 否認条件（重複・いたずら・キャンセル）、自己アフィ扱い | 案件の否認条件 |

**少ない数字で結論を急がない。** 目安として、CVR 1% の案件なら 100 クリックで平均1件。200 クリックで 0 件は「悪い兆候」だが「確定的な失敗」ではない。案件のジャンルごとの CVR はかなり違う（金融の申込は低め、物販は高めなど）ので、可能なら ASP の案件ページの「EPC」「確定率」と比べる。

## 3. 次にやること（最大3つ、効果が大きい順）
各項目に「なぜ」「具体的な作業」「かかる時間」「確認する数字と期間」を付ける。
例：
```
1. クリックが一番多いリンクを特定する
   なぜ：219クリックがどこから来ているか分からないと、直す場所が決まらない
   作業：A8の「広告リンク作成」でリンクごと（記事ごと・SNSごと）に別のリンクを発行する
   時間：30分
   確認：1週間後、リンク別のクリック数
```

## 4. 励ましと厳しさ
- 良い兆候があれば最初に伝える（例：「200以上クリックされているのは、あなたの文章に人を動かす力がある証拠です」）
- そのうえで、直視すべき点ははっきり伝える（例：「ただ、クリックする人と買う人が違う可能性が高いです」）
- 最後に、次の1歩だけを明確にする

結果を `output/YYYYMMDD_diagnose.md` に保存し、profile.md の「8. 今の数字」に追記してよいか聞く。
