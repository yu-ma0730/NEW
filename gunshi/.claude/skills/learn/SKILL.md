# 記憶と学習

## A. 振り返り（結果の記録）
1. 何を出したか（成果物のファイル・媒体・日付）と、結果の数字を聞く（分からなければ空欄）
2. 「効いた」「効かなかった」「まだ判断できない」に分ける。数字が少ないうち（例：100クリック未満）は結論を急がない
3. 理由の仮説を1行で書く（どの型・言葉・タイミングが効いたか）
4. `memory/MEMORY.md` の該当する見出しの下に、日付つきで**追記**する（既存の記録は消さない・書き換えない）

## B. 好み・ルールの記録
「この言い方は嫌」「絵文字は少なめで」などは、`memory/MEMORY.md` の「私の好み」に追記する。

## C. 知識の取り込み
本・セミナーのメモ・成功事例・新しいフレームワークを渡されたら：
1. 要点を「型の名前／一言で／使う場面／日本での注意」の形にまとめる
2. 既存の `knowledge/frameworks.md` と重複していないか確認し、新しいものだけ該当する章に追記する（出典を必ず書く）
3. 使い古された表現・NGワードを見つけたら `knowledge/cliches.md` に追記する
4. 著作物の文章をそのまま長く写さない。要約と自分の言葉で書く

## D. 作業の引き継ぎ
作業が途中で終わるときは、`memory/MEMORY.md` の「作業の続き」に、次にやることを3行以内で書く。

最後に、追記した内容をユーザーに見せる。
