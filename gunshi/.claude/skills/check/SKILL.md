# 法令・炎上リスクチェック

チェック対象（ユーザーが貼った文章、または `output/` のファイル）と `brief.md` の業種を確認する。

## チェック項目

### 1. 景品表示法
- **優良誤認**：品質・効果を実際より良く見せていないか。No.1・日本初・最高・業界最安 → 客観的な調査根拠（調査機関・時期・対象・方法）の記載はあるか
- **有利誤認**：二重価格（「通常価格」に販売実績はあるか）、「今だけ」「残りわずか」が事実か、カウントダウンがリセットされていないか、「〇〇万円相当の特典」の根拠
- **ステマ規制（2023年10月〜）**：事業者が関与した投稿・口コミに「広告」「PR」等の表示があるか
- **打消し表示**：「※個人の感想です」「※効果には個人差があります」で強い表現を打ち消そうとしていないか（打消しでは免責されない）

### 2. 薬機法・健康増進法（健康食品・化粧品・医療機器・サプリ・美容など）
- 健康食品で病気の治療・予防、身体の機能改善をうたっていないか（「血圧が下がる」「免疫力アップ」「痩せる」）
- 化粧品の効能が認められた範囲を超えていないか（「シミが消える」「アンチエイジング」「肌が再生」）
- 医師・専門家の推薦表現、ビフォーアフター写真の扱い

### 3. 特定商取引法・特定電子メール法
- 通販：事業者名・住所・電話番号・返品条件などの表記箇所があるか
- 定期購入：最終確認画面で総額・回数・期間・解約方法がわかるか（2022年改正）
- メール広告：オプトイン（事前同意）と配信停止方法の表示

### 4. アフィリエイト特有の注意
- **リンクの書き方**：すべてのリンクの直後が「 PR」（半角スペース＋PR）になっているか。なっていなければ修正案で `URL PR` に直す
- **ステマ規制**：アフィリエイトリンクを含む記事・投稿は広告にあたる。冒頭など分かりやすい位置に「PR」「広告」「アフィリエイト広告を利用しています」等の表示があるか（SNSは投稿ごとに）
- **広告主の表現ルール**：広告主（ASPの案件ページ）が禁止している表現・キーワードを使っていないか
- **ASP規約**：商標キーワードでのリスティング出稿禁止、自己アフィリエイト（セルフバック以外）、ポイントサイト・クリック誘導の禁止など
- **使っていない商品を使ったように書いていないか**（体験談の捏造は優良誤認にもなりうる）
- 公式サイトの情報（料金・キャンペーン）が古くなっていないか、確認日を書いているか

### 5. 炎上・ブランド毀損リスク
- 性別・年齢・容姿・職業へのステレオタイプ
- 災害・事件・他社の不祥事への便乗
- 競合を貶める比較
- 過度な煽り（「知らないと損」「〇〇な人はヤバい」）が日本の顧客に不快感を与えないか
