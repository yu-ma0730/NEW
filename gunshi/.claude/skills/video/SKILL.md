# 動画台本

`profile.md`（顔出しの可否・得意なこと）、`brief.md`、`memory/MEMORY.md`、`knowledge/frameworks.md` を読む。
媒体・長さ・目的（再生・登録・クリック・購入）を確認する。

## 1. 共通の設計
- **フック（冒頭）**：カールトンの6類型（人物・事実・逆説・警告・発見・挑発）から5案出し、1つ選ぶ
- **約束**：最後まで見ると何が手に入るかを、冒頭10秒以内に言う
- **パターン・インタラプト**：長尺は1〜2分ごとに、話題・画面・問いかけで注意をリセットする場所を入れる
- **CTA**：1本の動画で行動は1つ

## 2. 形式別
### ショート・TikTok・リール（15〜60秒）
```
| 秒 | 画面（映すもの・テロップ） | セリフ |
```
- 0〜2秒：フック（テロップでも同じ言葉を出す）
- 顔出しNGなら、手元・画面録画・画像スライドでの構成にする
- キャプション、ハッシュタグ、固定コメント案も出す

### YouTube 長尺（8〜15分目安）
- タイトル案 5つ（32字前後、キーワードは前半に）とサムネ文言案 3つ（10字前後）
- 構成：フック → 約束 → 自己紹介（10秒以内）→ 本編（章立て・チャプター用タイムスタンプ）→ まとめ → CTA
- 概要欄：要約、チャプター、リンク（すべて `URL PR` の形）。概要欄は5,000字、タイトルは100字まで

### VSL・ウェビナー（販売用）
- 構成：フック → 問題 → 気づきの物語（エピファニー・ブリッジ）→ 解決策 → 証拠 → オファー → 保証 → FAQ → 締切（実在するものだけ）→ CTA
- 日本の視聴者向けに、煽りは控えめ、「向いていない人」も伝える

## 3. 仕上げ
- `/gate` の観点（特に法令・PR表記・AIっぽさ・声に出して自然か）で自己点検
- `output/YYYYMMDD_video_<テーマ>.md` に保存
