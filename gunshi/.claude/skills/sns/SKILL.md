# SNS投稿

`brief.md` と `knowledge/frameworks.md`（ULSSAS・DECAX・心理トリガー）を読む。

## 1. 確認
媒体・本数・目的（認知／保存数／プロフィール遷移／LINE登録）を確認する。指定がなければ「Instagram 1週間分（7投稿）」で提案する。

## 2. 投稿の型（日本で反応が取りやすいもの）
| 型 | 狙い | 例 |
|---|---|---|
| 保存型（ノウハウ・まとめ） | 保存数→おすすめ表示 | 「〇〇な人がやりがちなNG5選」 |
| 共感型（あるある） | いいね・コメント | 「〇〇あるある」 |
| ストーリー型（失敗→気づき） | ファン化 | 「3年前、私は〇〇で失敗しました」 |
| 事例型（お客様の変化） | 社会的証明 | ※本人許可・誇張なし |
| 舞台裏型（作っている過程・人柄） | 親近感・信頼 | 「今日の工房」 |
| 季節・時事型 | 話題性 | 季節イベントに絡める |

1週間なら「保存型3：共感型2：ストーリー/舞台裏1：告知1」を目安にし、**告知は全体の2割以下**。

## 3. 媒体ごとの書式
- **Instagram（カルーセル）**：1枚目の表紙コピー（13字×2行以内）＋2〜9枚目のスライド文＋キャプション＋ハッシュタグ5〜10個（ビッグ・ミドル・スモールを混ぜる）
- **Instagram リール／TikTok**：冒頭2秒のフック文、構成（秒数つき）、テロップ、BGMの雰囲気
- **X**：140字以内（全角）で1投稿完結。スレッドにする場合は1投稿目だけで価値が伝わるように
- **Threads**：会話調・問いかけで終える
- **note**：タイトル案3つ＋見出し構成＋導入文

## 4. 注意
- インフルエンサー・アンバサダーに依頼する投稿や、自社が対価を払った投稿には **「PR」「広告」表記を必ず指示**（ステマ規制）
- 他社・他人を下げる比較、炎上しやすい話題（性別役割・容姿・政治・災害便乗）は避ける

## 5. 仕上げ
投稿カレンダー表＋各投稿の本文を `output/YYYYMMDD_sns_<テーマ>.md` に保存。
