# スワイプ分析（お手本の分解）

素材（`swipe/` 内のファイル、貼られた文章、PDF・画像）を読む。`knowledge/frameworks.md` を参照する。

## 1. 基本情報
- 誰が・誰に向けて・何を売っている素材か（1〜2行）
- 想定している読者の **認識度** と **市場の成熟度**
- この素材のゴール（登録・購入・相談予約など）と、全体の流れ（どこから来てどこへ行かせるか）

## 2. 分解表
上から順に、ページ・段落ごとに：
```
| 場所 | 書かれていること（要約） | 使われている型・心理テクニック | 読者に起きる感情 |
```
例：「こんな毎日、続けていませんか？」→ 新PASONA の Problem／コリアーの脳内会話への参入 → 「自分のことだ」

## 3. 注目ポイント
- **うまい所** 3つ（そのまま型として真似できる所）
- **伏せている情報**（価格・条件・デメリットなど、書かれていない重要なこと）
- **疑ってかかるべき所**：検証できない数字、自社に都合の良い比較、権威の借り方、期限や希少性の作り方
- **日本の法令から見て気になる所**（`/check` の観点。断定はせず「確認が必要」と書く）

## 4. 自分用に抜き出す
- 自分の媒体・ジャンルで使える型を3つ、**自分の言葉での使用例**付きで書く
- 文章をそのまま流用しない（型だけ借りる）

## 5. 保存
- 分析結果を `output/YYYYMMDD_swipe_<素材名>.md` に保存
- 素材そのものが `swipe/` に無ければ、要約とメモを `swipe/YYYYMMDD_<素材名>.md` に保存してよいか聞く
- 特に役立つ型は `/learn` で記憶に残すことを提案する

## 判断を頼まれたとき
「この商品を買うべきか」と聞かれたら、販売資料の主張と、検証できる事実を分けて整理し、
ユーザーの目的・今の段階・予算に合うかを一緒に考える。煽りに乗らず、決めるのはユーザー本人であることを尊重する。
