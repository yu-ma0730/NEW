# 市場調査・N1分析

`profile.md`、`brief.md`（またはその案件の `projects/<案件>/brief.md`）を読む。
Web検索が使える場合は、検索して得た事実には出典URLと確認日を付ける。使えない場合は、ユーザーに調べてもらう項目を「調査リスト」として出す。

## 1. 3C分析
| | 調べること | 分かったこと | 出典・確認日 |
|---|---|---|---|
| Customer（読者） | 誰が・何に困って・どんな言葉で検索／投稿しているか | | |
| Competitor（競合） | 同じテーマで上位の記事・伸びているアカウント3〜5つ。何が強く、何が足りないか | | |
| Company（自分） | 自分にしか語れない経験・強み・使える時間 | | |

## 2. 読者の本音を集める（セールス・ディテクティブ）
- Yahoo!知恵袋、口コミサイト、Amazon・楽天のレビュー（特に★2〜3）、X・Threads の投稿、YouTube のコメント欄から、**読者の生の言葉**を10個集める（要約せず、言い回しのまま）
- そこから「悩み」「不安」「理想」「よく使う言葉」に分類する

## 3. N1分析（たった1人の読者）
架空の平均像ではなく、**実在しそうな1人**を描く：
- 名前（仮）・年齢・仕事・1日の過ごし方
- このテーマで困った具体的な場面
- これまで試してダメだったこと
- 頭の中の声（コリアーの「脳内会話」）
- 買う直前に背中を押すもの／止めるもの
- どこで情報を見ているか（媒体・時間帯）

ユーザー自身や知人に近い人がいれば、その人を N1 にするのが一番強い。

## 4. チャンスの整理
- **飢えた群衆**：今すぐ欲しがっている人はどこにいるか
- 競合が書いていない・答えていない疑問 3つ
- 自分の経験で勝てる切り口 3つ
- 最初の1か月でやること（媒体・テーマ・本数）

## 5. 保存
`output/YYYYMMDD_research_<テーマ>.md`（案件フォルダがあればそこへ）に保存し、次は `/concept` を案内する。
