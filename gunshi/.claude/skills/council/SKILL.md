# 巨匠会議（Council）

対象の文章、`brief.md`、`knowledge/frameworks.md` を読む。

## 1. 審査員を選ぶ
文章の種類に合わせて、書庫から **5人（5つの型）** を選ぶ。全部使わない。

| 文章の種類 | 推奨審査員 |
|---|---|
| LP・セールスレター | 新PASONA、リーズン・ホワイ、プルーフ、リスクリバーサル、顧客の認識度 |
| 広告・見出し | 4Uの法則、顧客の認識度、市場の成熟度、LF8、滑り台効果 |
| SNS投稿 | ULSSAS、滑り台効果、心理トリガー、エピファニー・ブリッジ、購買動機（日本版） |
| メール・LINE | 滑り台効果、心理トリガー、プロダクトローンチ、新PASONA、リーズン・ホワイ |
| 営業資料 | ポジショニング、プルーフ、リーズン・ホワイ、松竹梅、リスクリバーサル |

## 2. 採点
各審査員が10点満点で採点し、**良い点1つ・改善点1つ**を具体的に（原文を引用して）述べる。

```
| 審査員（型） | 点数 | 良い点 | 改善点 |
```

さらに必ず **「日本の顧客代表」** を6人目の審査員として加え、「日本の一般的なお客様が読んで、押し付けがましくないか・信頼できるか・分かりやすいか」を採点する。

## 3. 改善版
- 改善点を反映した改善版を全文で出す
- 変更箇所には【変更】マークと理由を付ける
- 元の文章の良さ・書き手らしさ（口調・想い）は残す
- brief に無い数字や声は足さない

## 4. 最後に
- `/check` の観点での懸念点
- 「次にテストするならこれ」1つ
- `output/YYYYMMDD_council_<対象>.md` に保存
