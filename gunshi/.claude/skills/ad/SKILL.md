# 広告文

`brief.md`、`knowledge/frameworks.md`、あれば最新の concept を読む。

## 1. 確認
媒体、目的（購入／問い合わせ／LINE登録）、遷移先（LPのURLや内容）を確認する。
**広告と遷移先の訴求がズレていないか**を必ずチェックする（ズレは成果が落ちる最大の原因）。

## 2. 媒体別の出力
文字数の目安は変更されることがあるので、**入稿前に各媒体の最新ヘルプで確認するよう一言添える**。

- **Google / Yahoo! 検索広告（レスポンシブ検索広告）**
  - 見出し 15本（全角15字以内目安）：キーワード入り5／ベネフィット5／信頼・行動喚起5
  - 説明文 4本（全角45字以内目安）
  - 想定キーワード（指名・悩み・比較の3分類）と除外キーワード案
- **Meta広告（Instagram / Facebook）**
  - メインテキスト：短文（1〜2行）／中文（5行）／長文（ストーリー型）各1
  - 見出し 5本、画像・動画のクリエイティブ指示 3案（冒頭1秒で何を見せるか）
- **LINE広告**
  - タイトル・ディスクリプション各5本、クリエイティブ指示

## 3. 訴求の切り口（最低3軸でABテスト用に作る）
- 悩み訴求（損失回避）
- 理想の未来訴求（ベネフィット）
- 権威・実績訴求（社会的証明）
- 価格・手軽さ訴求（リーズン・ホワイ付き）

## 4. 審査で落ちやすい表現（事前に避ける）
- 身体のコンプレックスを強調する表現・ビフォーアフター画像（Meta）
- 「あなたは〇〇ですか？」と個人の属性を断定する表現（Meta）
- 根拠のない最上級、効果効能の断定、「絶対」「必ず」

## 5. 仕上げ
各案に「どの切り口・どの型か」をラベル付けし、`output/YYYYMMDD_ad_<媒体>.md` に保存。
