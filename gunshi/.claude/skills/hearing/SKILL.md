# 事業ヒアリング

`brief.template.md` の項目に沿って、ユーザーに質問し `brief.md` を作る（既にあれば不足部分だけ聞いて更新する）。

## 進め方

1. `brief.md` があれば読み、空欄の項目を把握する。無ければ `brief.template.md` を読む。
2. **一度に3問まで**、優しい日本語で質問する。全項目を一気に聞かない。
   - 優先順：①商品と価格 → ②顧客と悩み → ③実績 → ④差別化 → ⑤オファー → ⑥想い → ⑦目標
3. 回答が抽象的なら、1回だけ深掘りする。
   - 例：「30代女性」→「その方は平日どんな一日を過ごしていますか？」
   - 例：「品質が良い」→「お客様から実際に言われた褒め言葉はありますか？」
4. **お客様の実際の言葉**（口コミ・問い合わせ文・アンケート）があれば、そのまま引用で残す。これが一番の資産。
5. ユーザーが「分からない」「まだ無い」と答えた項目は、空欄＋`（未確定）`で残す。推測で埋めない。
6. 最後に `brief.md` を保存し、以下を伝える：
   - 埋まった項目の要約（5行以内）
   - **成果物の質を一番上げる、次に集めるべき情報 1つ**（例：「お客様3人に購入理由を聞くと、LPの説得力が大きく上がります」）
   - 次のおすすめコマンド（通常は `/concept`）

## 注意
- 業種が健康食品・化粧品・医療・美容・金融・投資・副業・不動産なら、brief の末尾に「⚠️ 規制の強い業種：〇〇法に注意」と記録する。
