# ヒアリング

## 0. どちらを作るか
- `profile.md`（**あなた自身**：立場・AI・ASP・ジャンル・媒体・経験・目標・数字）→ テンプレートは `profile.template.md`
- `brief.md`（**売る商品**：自社商品、またはアフィリエイトで主に紹介する案件）→ テンプレートは `brief.template.md`

profile.md が無ければ profile から始める。アフィリエイターの場合、brief.md は「主力案件1つ」について作る。

## 1. 選択肢がある項目は選択肢で聞く
`AskUserQuestion` ツールが使える場合は、テンプレートの選択肢をそのまま選択式で出す（複数選べる項目は複数選択にする）。1回に4問まで。
選択肢が5個以上ある項目（ASP・ジャンル・媒体など）は、代表的な3〜4個を出し、残りは「その他」で入力してもらう。
ユーザーが `profile-form.html` で作った文章を貼り付けた場合は、それをそのまま profile.md として保存し、空欄だけ質問する。

## 2. 自由記述の項目
- 抽象的な回答は1回だけ深掘りする（例：「副業ジャンル」→「その中でも、あなた自身が経験したことはありますか？」）
- **実体験・お客様（読者）の実際の言葉**があれば、引用のまま残す。これが一番の資産
- 「分からない」は空欄＋`（未確定）`。推測で埋めない
- ASP のID・パスワード・口座番号が書かれていたら、保存せず削除するよう伝える

## 3. ASP管理画面の数字・スクショ
数字やスクショが貼られたら、profile.md の「8. 今の数字」に転記し、続けて `/diagnose` を提案する。

## 4. 最後に伝えること
- 埋まった項目の要約（5行以内）
- **成果を一番上げる、次に集めるべき情報 1つ**
- 次のおすすめコマンド（数字があれば `/diagnose`、ページがあれば `/page`、どちらも無ければ `/concept`）

## 注意
- ジャンルが金融・美容・健康・医療・不動産・副業・情報商材なら、ファイル末尾に「⚠️ 規制の強いジャンル：〇〇法に注意」と記録する。
