# 使い古された表現リスト（既視感チェック用）

`/gate` の「既視感」チェックで使う。これらは**禁止ではない**が、使うと「どこかで見た文章」「AIっぽい文章」に見えやすい。
見つけたら、**具体的な数字・場面・体験**に置き換える。気づいた表現はどんどん追記して育てる。

## どのジャンルでも
| 使い古された表現 | 置き換えの方向 |
|---|---|
| 画期的な／革新的な／最先端の | 何がどう新しいのかを1文で（「〇〇を△分で終わらせる」） |
| 圧倒的な／驚くほど／劇的に | 実際の数字か、使った人の一言 |
| 〜ではないでしょうか？（多用） | 言い切るか、読者の心の声で問う |
| いかがでしたか？ | 記事の結論や次の行動を1行で |
| 結論から言うと（多用） | そのまま結論を書く |
| 〜と言っても過言ではありません | 削る |
| 今すぐ／今だけ（根拠なし） | 本当の締切があるときだけ、日付で |
| 誰でも簡単に | 「〇〇が分かる人なら」「平日30分あれば」など条件を正直に |
| 人生が変わる | どんな日常がどう変わるかを具体的な場面で |
| 〜の秘密を大公開 | 何が分かるのかを中身で書く |
| ぜひチェックしてみてください | 誰が・なぜクリックすべきかを書く |

## AIっぽさが出やすいパターン
- 「まず」「次に」「最後に」の機械的な並び
- 毎段落の最後が「〜でしょう」「〜が大切です」
- 箇条書きの各項目が同じ長さ・同じ語尾
- 「〜することで、〜することができます」の重ね
- 結びが毎回「いかがでしたか」「参考になれば幸いです」

## ジャンル別
### 副業・稼ぐ系 ⚠️
- 不労所得／ほったらかし／スマホ1台で／月収100万 → 景表法・特商法リスクも高い。実際の作業時間と結果の幅を書く

### 美容・健康 ⚠️
- 魔法のような／-10歳／みるみる → 薬機法リスク。使用感・続けやすさ・成分の事実で

### 通信・金融
- 業界最安級／お得すぎる → 比較表で「どの条件なら安いか」を示す

### ガジェット・AIツール
- 神ツール／これ一択／革命 → 誰に向くか・向かないかを明記
