# 媒体別のルールとやり方（文字数の上限・リンクの書き方）

すべての成果物はこのファイルに従う。自動投稿は使わず、**本人が読んで直してから手で投稿する**前提で書く。

## 全媒体共通：リンクの書き方（必ず）
- リンクは必ず **URL の直後に半角スペース＋「PR」** を付ける：`https://px.a8.net/... PR`
- 全角スペース（`URL　PR`）や「（PR）」は使わない。必ず `URL PR` の形
- 実際の URL が分からない下書きでは `【案件リンク】 PR` と書く
- ブログ・note は、これに加えて記事の冒頭に「本記事はアフィリエイト広告を利用しています」を入れる
- 「クリックして」など、クリックをお願いする表現は使わない（ASP規約）

## 文字数の上限
| 媒体 | 上限 | 数え方・メモ |
|---|---|---|
| X | **全角140字**（半角280字） | 無料アカウントの上限。全角1字＝2、半角1字＝1、URLは1本23（半角）として数える |
| Threads | **500字** | 1投稿。返信・引用も同じ |
| ブログ | **5,000字**（目安4,500字） | 改行は数えない。調査では3,000〜5,000字の記事が上位に多い。ただしGoogleは文字数を評価の基準にしていないので、狙うキーワードの上位記事の文字数も確認する |
| note | 5,000字 | ブログと同じ目安 |
| Instagram | 2,200字 | キャプション。ハッシュタグは5〜10個（上限30個） |
| TikTok | 2,200字（目安） | キャプション。短いほど読まれる |
| YouTube | 概要欄5,000字・タイトル100字 | 概要欄の最初の2〜3行が大事 |

上限ぎりぎりではなく、**少し短く**収める。

## 媒体ごとのやり方
### X
- 1投稿で話を完結させる。リンクは1投稿に1本まで
- 宣伝の投稿は全体の2割以下。同じ文章を繰り返し投稿しない
- ハッシュタグは0〜2個

### Threads
- 宣伝色を弱め、問いかけで終えて会話を生む
- 同じ文章を繰り返し投稿しない

### ブログ
- H2・H3 の見出しで構成し、比較表・デメリット・向いていない人を入れる
- 自分で撮った写真や体験を入れる。料金やキャンペーンには確認日を書く
- 構成は `/blog` を使う

### YouTube・TikTok・Instagram・note
- `/video` `/sns` の手順に従い、PR 表記と `URL PR` を必ず入れる
