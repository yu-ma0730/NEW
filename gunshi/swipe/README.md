# スワイプファイル（お手本・競合の保存場所）

反応が良さそうな他人の LP・広告・投稿・メール・台本を保存しておくフォルダです。
`/swipe swipe/ファイル名` で、どんな型・心理テクニックが使われているかを分解し、自分用の「使える型」を抜き出します。

- 1つの素材につき1ファイル（例：`swipe/20261012_NEO_紹介資料.md`）
- 先頭に「どこで見たか・いつ・媒体・自分が反応したか」をメモ
- 画像や PDF の場合は、文章を書き起こすか、Claude Code に読み込ませて要約を保存

⚠️ 保存した文章は**分析用**です。そのままコピーして使うと著作権の問題になります。型だけを借りて、言葉は自分で書きます。
