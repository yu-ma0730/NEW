# 自分だけのプロンプト置き場（GitHub には上がりません）

このフォルダの中身は `.gitignore` で除外されていて、**GitHub に push されません**（この README だけが上がります）。
リポジトリは公開なので、大事な手法やプロンプトを `knowledge/` など他の場所に書くと、誰でも読めてしまいます。秘密にしたいものは必ずここに置いてください。

- 1つの手法につき1ファイル（例：`prompts/threads_問いかけ型.md`）
- Claude Code で「prompts/threads_問いかけ型.md を使って投稿を作って」のように使えます

メインページの各媒体にある「手法・プロンプト集」は、合言葉で暗号化してブラウザにだけ保存する別の置き場です。
