# 軍師（GUNSHI）― あなた専用の AIマーケティング部門

世界のマーケティングの「型」46個と日本人の心の動きを、**日本の顧客・文化・法律**に合わせて組み込んだ Claude Code 用ツールです。
自分の PC で動き、追加の月額料金はかかりません（Claude Code の利用料のみ）。

## できること

| コマンド | 内容 |
|---|---|
| `/hearing` | ヒアリング（最初に1回。あなた自身の `profile.md` と商品の `brief.md` を作る） |
| `/diagnose` | ASP（A8.net など）の数字から、どこで成果が止まっているか診断 |
| `/page` | 自分のブログ記事・LP・投稿を貼り付けて診断＆書き直し |
| `/research` | 市場調査・3C・N1分析・競合リサーチ（事前マーケティング） |
| `/concept` | コンセプト・ポジショニング・キャッチコピー |
| `/lp` | LP・セールスレター |
| `/step` | LINE／メールのステップ配信 |
| `/sns` | Instagram・X・Threads・TikTok・note の投稿 |
| `/ad` | Google・Yahoo!・Meta・LINE 広告文 |
| `/slide` | 日本の BtoB 向け営業スライド（稟議対応） |
| `/blog` | ブログ記事（キーワード→構成→本文5,000字まで→PR表記） |
| `/video` | YouTube・ショート・TikTok・リール・VSL・ウェビナー台本 |
| `/check` | 景表法・薬機法・特商法・ステマ規制・炎上リスクのチェック |
| `/gate` | 品質ゲート：15の関所（AIっぽさ・既視感・4U・法令・PR表記など）を全部通るまで直す |
| `/swipe` | お手本・競合の広告や販売資料を分解して、使える型を抜き出す |
| `/learn` | 結果の振り返りや本の知識を記憶（memory/MEMORY.md）に追加して、軍師を育てる |
| `/council` | 巨匠会議：複数の型で既存の文章を採点・改善 |

## 日本向けにしたポイント

- **日本生まれ・日本で定着した型を追加**：新PASONA（神田昌典）、AISAS・DECAX（電通）、ULSSAS（ホットリンク）、三方よし、松竹梅の法則
- **海外の型を日本向けに調整**：煽りを抑え、「安心・実績・口コミ・丁寧さ」を重視
- **法令チェックを標準装備**：偽の締切、根拠のない No.1、PR 表記なし、効果の断定などを自動で指摘
- **日本のチャネル前提**：LINE公式アカウント、Yahoo!広告、note、稟議文化、季節イベント
- **捏造しない設計**：実績やお客様の声を勝手に作らず、`【要確認】` で穴あきにする

## メインページ（profile-form.html）の流れ

1. **AIの接続**：Anthropic APIキーを入力（PCのブラウザでこのHTMLを開いたとき）。claude.ai 上の公開ページでは、キーなしで自分の Claude アカウントで動きます
2. **媒体を選ぶ**：YouTube・ブログ・X・Threads・TikTok・Instagram・note
3. **スクショを取り込む**：管理画面のスクショを選んで「AIで読み取って反映」→ 数字が項目に入り、画像の下にも読み取った値が出る
4. **段階と準備のチェック**：「まだ何もしていない」「これから始める」「事前調査中」〜「収益が出ている」と、準備のチェックリスト
5. **マーケティング開始**（各媒体ページの一番下）：その媒体用に、違う「型」の戦略を5本作る。各戦略は「〜型・本文（そのままコピー可）・評価点・合計点・感想」の形で、最後に総合判断。評価点は ICE（影響・確信度・手軽さ 各10点）＋4Uの法則（有益・緊急・独自・具体 各4点）の46点満点。文字数・`URL PR`・法令の関門を通らない本文は、点数に関係なく使えない扱い。結果は媒体ごとに保存され、メインページの「作った戦略」から開ける

6. **投稿の記録と振り返り**（各媒体ページ）：投稿した本文と型を記録し、数日後に数字（Xなら表示回数・いいね・プロフィール表示・リンククリック）を入れると、型ごとの成績が表にまとまる。1つの型につき3本以上たまるまでは「まだ判断できない」と表示。「AIで振り返る」で効いたこと・次にやることを出し、記録は次の「マーケティング開始」の判断材料（確信度）にも使われる。戦略の本文や下書きの「投稿したので記録」ボタンからも追加できる

7. **手法・プロンプト集**（各媒体ページ）：自分の手法やプロンプトを保存し、1つずつ「コピー」できる。このブラウザにだけ保存され、どこにも送信されず、GitHub にも入らない（合言葉の鍵は不要と判断して外した）。ブラウザのデータを消すと消えるので、ときどき「バックアップ」をコピーして保存しておく。Claude Code 側で使う秘密のプロンプトは `prompts/`（GitHub に上がらない）に置く

8. **紹介する案件と体験の証明**（各媒体ページの「紹介する案件」）：ASPのプログラム詳細や商品ページのテキストを貼り、画像も入れて「読み込んで欄に入れる」→ 商品名・ターゲット・商品情報・広告主の禁止事項が入る。その下の「体験の証明」で、商品と一緒に写した写真・契約や購入の完了画面・利用中の画面をアップして「AIで確認する」。確認できると、
   - チェック項目の「体験の証明あり」に自動でチェックが入る
   - AIが書く文章が、確認できた事実と自分のメモ（いつから・良かった点・不満な点）を使った体験談に変わる（作った文章は「体験ありで書き直す」でも変えられる）
   - ほかの媒体で証明した商品は、選ぶだけで使い回せる
   - 証明がない商品では「使ってみた」「愛用」などの体験の表現を使わず、調べた情報として書く。体験の表現が入った文章はコピーできない

10. **4人の投稿づくり**（Threads・X・Instagram・TikTok のページ）：「手法・プロンプト集」で使うプロンプトに「使う」のチェックを入れ、「4人に5本ずつ書いてもらう」を押すと、書き方の違う4人（Lv1〜Lv4）が5本ずつ、合計20本を書く。そのあと、書いた本人以外の3人が採点（フック力・具体性・逆張り強度・共感性・コメント誘発力 各20点）し、チェックを通る中で一番点数の高い1本をコピーできる。商品の情報は「紹介する案件」から使う。リンクの置き場所は媒体に合わせる（Threadsはツリー投稿、Xは返信ポスト、Instagram・TikTokはプロフィールのリンク）。YouTube・ブログ・note は長い文章なので対象外

9. **文章のチェック項目**（下書き・戦略の本文ごと）：文字数、`URL PR`、法律に触れる表現（絶対・No.1・最安・痩せる・稼げる・クリック誘導など）、体験の表現を自動でチェック。☒ が1つでもあるとコピーできない。「公式サイトで確認した」「声に出して読んだ」は自分でチェックする（残っているとコピー後に知らせる）

### 普通のWebページとして開く
`docs/index.html` が、ブラウザでそのまま開けるWeb版です（中身は `profile-form.html` と同じ）。`profile-form.html` を直したら `sh gunshi/tools/build-web.sh` で作り直してください。
GitHub Pages で公開すると `https://yu-ma0730.github.io/NEW/` で開けます（Settings → Pages → Branch でこのブランチと `/docs` を選ぶ）。
Web版では claude.ai のAIは使えないので、AIの機能（スクショ読み取り・下書き・マーケティング開始）には APIキーが必要です。

APIキーはブラウザから Anthropic に直接送られます。「この端末に保存する」をオフにすれば、ページを閉じると消えます。

## 媒体ごとのルール（必ず守る）

- **リンクは必ず `URL PR`**（URL の直後に半角スペース＋PR）
- **文字数の上限**：X 全角140字／Threads 500字／ブログ 5,000字（目安4,500字）／note 5,000字／Instagram 2,200字／TikTok 2,200字／YouTube 概要欄5,000字
- **自動投稿はしない**：下書きまでを作り、自分で読んで直してから手で投稿する
- 詳しくは `knowledge/platform-rules.md`。メインページの各媒体ページにも「ルールとやり方」と、文字数・PR のチェッカーがあります

## プロフィールの入力（選択肢から選ぶだけ）

`profile-form.html` をブラウザで開き、**最初に主戦場の媒体（YouTube・ブログ・X・Threads・TikTok・Instagram・note）を選びます**。媒体をタップすると、その媒体専用のページ（段階・テーマ・形式・収益化・数字・ページ貼り付け）に進みます。
段階は「まだ何もしていない」「事前マーケティング（リサーチ・競合調査中）」から「収益が出ている」まで選べます。
共通プロフィールでは次の項目を入力できます。最後に「profile.md をコピー」を押して、`gunshi/profile.md` に保存してください。

- 立場（アフィリエイター／自分の商品／両方）
- 使っているAI・使う予定のAI（Claude、ChatGPT、Gemini、Copilot など）
- 使っているASP（A8.net、もしも、バリューコマース、afb など）と状態
- ジャンル（⚠ 規制の強いジャンルが分かる）・媒体・URL
- 経験・累計報酬・使える時間・予算・顔出し・得意なこと・実体験の有無
- 目標と困っていること
- ASPの数字（入れるとCVRと「期待される成果数」をその場で計算）
- 紹介している案件（報酬・成果条件）
- **ページの貼り付け**（記事・LP・投稿を本文ごと。`pages/` 用の文章もコピーできる）

Claude Code の `/hearing` でも、同じ項目を選択式で質問してもらえます。

## 使い方

```bash
# 1. Claude Code をインストール済みの PC で
cd gunshi
claude

# 2. 最初にヒアリング（brief.md が作られます）
/hearing

# 3. あとは作りたいものを呼ぶだけ
/concept
/lp
/check output/20261012_lp_〇〇.md
```

成果物は `output/` フォルダに保存されます。

## フォルダ構成

```
gunshi/
├── CLAUDE.md               # 軍師の基本ルール（毎回自動で読み込まれる）
├── profile-form.html       # プロフィール入力フォーム（ブラウザで開く）
├── profile.template.md     # あなた自身の情報のテンプレート
├── profile.md              # あなたのプロフィール（※公開リポジトリには入れない）
├── brief.template.md       # 売る商品のテンプレート
├── brief.md                # /hearing で作られるあなたの事業情報（※公開リポジトリには入れない）
├── knowledge/
│   ├── frameworks.md       # 46の型・巨匠の視点・日本人の心の動き
│   └── cliches.md          # 使い古された表現リスト（既視感チェック用）
├── memory/MEMORY.md        # 軍師の記憶（効いたこと・好み・作業の続き）
├── projects/               # 案件ごとのフォルダ（混ざらずに複数同時進行）
├── swipe/                  # お手本・競合の素材置き場
├── pages/                  # 診断したいページを貼るフォルダ（_template.md をコピーして使う）
├── output/                 # 成果物
└── .claude/skills/         # 各コマンドの中身（自由に編集OK）
```

## 育て方（ここが一番大事）

このツールの本当の強さは「型」ではなく **`brief.md` に入るあなたの一次情報** です。

- お客様の **実際の言葉**（口コミ・問い合わせ・アンケート）を brief.md に貼るほど、文章が良くなります
- 反応が良かった投稿や広告を `knowledge/` に `winners.md` として追記すると、あなた専用の型が育ちます
- 自分の業界の型や NG ワードを見つけたら、`knowledge/frameworks.md` に書き足してください
