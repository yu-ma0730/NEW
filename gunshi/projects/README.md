# 案件フォルダ

紹介する案件（または自分の商品）が複数ある場合は、案件ごとにフォルダを分けます。混ざらないので、何案件でも同時に進められます。

```
projects/
└── 格安SIM_〇〇モバイル/
    ├── brief.md       # その案件の情報（/hearing で作成）
    ├── research.md    # 市場・競合・読者の調査（/research）
    ├── concept.md     # コンセプト（/concept）
    └── output/        # その案件の記事・投稿・台本など
```

Claude Code で「〇〇の案件で進めて」と言えば、そのフォルダの brief.md を読んで作業します。
