# スレッズ市場調査ノート

Threads（スレッズ）で発信を始める前の市場調査を、6 ステップで進めるためのツールです。
`index.html` をブラウザで開くだけで使えます（サーバー不要）。

| Step | 内容 | やること |
|---|---|---|
| 1 | ジャンル調査 | 候補ジャンルごとに **ボリューム / 収益化 / 発信内容** を調べて 5 段階評価。重み付きの総合点で比較して 1 つに決める |
| 2 | 競合分析 | 伸びているアカウントを記録。ER（平均いいね ÷ フォロワー）を自動計算 |
| 3 | ターゲット | ペルソナを 1 人に絞る |
| 4 | ポジション | 競合の隙 × 自分の強みでポジション文とプロフィール文（150 字カウンター）を作る |
| 5 | 投稿設計 | 頻度・時間帯・型の配分・導線・ネタ帳・下書き（500 字カウンター） |
| 6 | KPI・検証 | 目標と週次ログ、フォロワー推移グラフ、30 日後の判断チェック |
| まとめ | レポート | Markdown レポートと JSON バックアップをコピー / 復元 |

- 各キーワードから Threads の検索結果へ直接飛べます。
- 数値は手入力です（Threads の公式 API は他人の投稿の検索・集計に制限があるため）。
- データはブラウザの localStorage に保存されます。消えると困る場合は「まとめ」からバックアップをコピーしてください。
