# 📚 Book Explorer（データ可視化ダッシュボード）

[Books Scraper](../web-scraper/)（ツール2）で集めた書籍データを、
**検索・絞り込み・グラフ表示**できる Web ダッシュボードです。

HTML / CSS / JavaScript だけで作っており、外部ライブラリもサーバーも不要です。
そのまま **GitHub Pages** などで公開できます。

## 🎯 機能

- **集計カード**：表示中の冊数・平均価格・平均評価・カテゴリ数
- **絞り込み**：書名検索 / カテゴリ / 評価 / 価格の範囲
- **並び替え**：書名・価格（安い順/高い順）・評価
- **グラフ**（すべて絞り込みに連動）
  - カテゴリ別の冊数（上位10）… バーをクリックするとそのカテゴリで絞り込み
  - 価格の分布（£5 刻み）
  - 評価の分布
- **書籍一覧**：表紙画像つきカード、24件ずつのページ送り
- **CSV 書き出し**：絞り込んだ結果をそのままダウンロード
- **JSON 読み込み**：スクレイパーで取り直した `books.json` を画面から読み込み
- **スマホ対応・ダークモード対応**

## 🚀 使い方

### 方法1：ローカルサーバーで開く（おすすめ）

```bash
cd book-explorer
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。`data/books.json` が自動で読み込まれます。

### 方法2：ファイルを直接開く

`index.html` をダブルクリックで開いた場合、ブラウザの安全機能によりデータは自動で読み込まれません。
右上の **「JSONを読み込む」** から `data/books.json` を選んでください。

### データを最新にする

```bash
cd web-scraper
python scraper.py --output-dir ../book-explorer/data
```

## 🧱 構成

```
book-explorer/
├── index.html        # 画面の骨組み
├── style.css         # 見た目（スマホ・ダークモード対応）
├── app.js            # 読み込み・絞り込み・グラフ描画
└── data/books.json   # 表示するデータ（web-scraper の出力）
```

## 🔒 安全面の配慮

- 読み込んだデータは `textContent` で表示し、HTML として解釈しない（悪意あるデータによるスクリプト実行を防ぐ）
- `http` / `https` 以外のリンク（`javascript:` など）は使わない

## 📄 データについて

データ出典：[Books to Scrape](https://books.toscrape.com/)（スクレイピング練習用のデモサイト）。
価格・評価は架空の値です。表紙画像は同サイトから直接表示しています。
