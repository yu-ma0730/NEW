# AB手法 サインツール（TradingView / Pine Script v6）

ハイトレFXさん（YouTube「ハイトレFX億トレーダーへの道」）の考え方をもとに作った、**非公式**の TradingView インジケーターです。

> ⚠️ **大事な注意**
> 「AB手法」の厳密なルール（A・B の正確な定義、使う移動平均の期間など）は、ネット上の公開情報では確認できませんでした。
> このツールは、下の「調査でわかったこと」から組み立てた **推定仕様** です。ご本人の動画で説明されているルールと違う部分があれば、パラメータを変えるか、ルールを教えてもらえればコードを直します。

---

## 調査でわかったこと

| 項目 | 内容 |
|---|---|
| 手法の考え方 | チャートに繰り返し出るパターンを「型」として覚え、同じ形が出たら入る |
| 狙う波 | エリオット波動の **3波**（いちばん伸びやすい波） |
| 時間足 | 4時間足で環境認識 → 15分足などの押し目でエントリー、ピラミッティング（買い増し）あり |
| 「AB手法」 | 「勝率9割超え『AB手法』の勝ちパターン」というショート動画あり。文章での詳しい定義は見つからず |

## このツールのルール（推定仕様）

```
買いの場合                         売りの場合（上下反対）

          B ← ここを終値で抜けたら BUY      A
         / \        /                        \      C
        /   \      /                          \    / \
       /     C ───                             \  /   \
      /   （押し目）                             B      \ ← B を終値で割ったら SELL
     A
  （1波の起点）
```

1. **A** … 1波の起点（スイング安値）
2. **B** … 1波の終点（スイング高値）
3. **C** … 2波の押し目。条件は次の 2 つ
   - A を下に抜けていない（エリオット波動の基本ルール）
   - AB の **38.2%〜78.6%** 戻している（変更できます）
4. **BUY サイン** … C の確定後、**終値で B を上抜けた足**（＝3波入り）
5. **上位足フィルター** … 4時間足の 20EMA より上で、EMA が上向きのときだけ買いサインを出す（売りは逆）
6. **利確・損切りの目安**
   - TP1 = C + (B − A) × 1.0（N値 / AB=CD）
   - TP2 = C + (B − A) × 1.618
   - SL = C（または A を選べます）
7. 次のときはセットアップを取り消します：C を割った／50 本以内に B を抜けなかった／上位足と逆方向だった

## TradingView への入れ方

1. TradingView でチャートを開き、画面下の **「Pine エディタ」** をクリック
2. 中身をすべて消して、[`ab_signal.pine`](./ab_signal.pine) の内容を丸ごと貼り付ける
3. **「保存」** → **「チャートに追加」**
4. おすすめ：15分足〜1時間足のチャートで、上位足を「240（4時間足）」のまま使う

### アラート（通知）の設定

1. チャート上部の ⏰「アラート」をクリック
2. 条件で「AB Signal」を選ぶ
3. 次のどちらかを選ぶ
   - **「AB 買いサイン」/「AB 売りサイン」** … シンプルな通知
   - **「alert() 関数呼び出しのみ」** … エントリー価格・SL・TP1・TP2 入りの通知

## 設定の説明

| グループ | 項目 | 初期値 | 説明 |
|---|---|---|---|
| スイング検出 | ピボット 左 / 右バー数 | 5 / 3 | 大きくすると大きな波だけを拾う。右バー数のぶん、C の確定が遅れる |
| 押し・戻し | 最小 / 最大押し率 | 0.382 / 0.786 | C が AB をどれだけ戻したら「押し目」とみなすか |
| 押し・戻し | 最大待機バー数 | 50 | C 確定からこの本数以内に B を抜けないと取り消し |
| 上位足 | 上位足 / EMA 期間 | 240 / 20 | 環境認識に使う足と EMA。**チャートの足より長い足**を選んでください |
| 利確・損切り | 損切り位置 | C点 | 「A点」にすると損切りは広く、だましに強くなる |
| 利確・損切り | TP1 / TP2 倍率 | 1.0 / 1.618 | AB の値幅の何倍を C から伸ばすか |

## リペイント（後からサインが消える現象）について

- サインは**足が確定してから**出ます。確定したサインは後から消えません。
- 上位足の EMA は**確定済みの足**だけを見ているので、未来のデータは使っていません。
- A・B・C の点は、スイングが確定するまで「右バー数」本ぶん遅れて決まります。これは過去チャートでも同じ条件で計算しています。

## 使う前に

- 「勝率9割」などの数字はこのツールでは確認していません。まずは**過去チャートでサインの出方を確かめてから**、少ないロットで試してください。
