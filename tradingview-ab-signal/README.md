# ハイトレ式 20/200EMA 手法 サインツール（TradingView / Pine Script v6）

ハイトレFXさん（YouTube「ハイトレFX億トレーダーへの道」）の動画「移動平均線を使った高勝率手法」で説明されているルールを、TradingView のインジケーターにしたものです。**非公式**です。

動画では 5 分足のゴールドで検証していて、2025年4月末〜8月で **13 回エントリー・12勝1敗（勝率92%）、見送り 9 回** と紹介されています。

## 手法のルール（動画より）

| 手順 | 内容 |
|---|---|
| 1. 方向を決める | **20EMA が 200EMA より上 → 買いだけ**、下 → 売りだけ（ゴールデンクロス / デッドクロス） |
| 2. 待つ | 価格が **200EMA にタッチ**するのを待つ |
| 3. 入る | タッチ後に **きれいな斜めライン** が引けたら、それを抜けた足でエントリー。**ダブルボトム / ダブルトップ** のネックライン抜けでもOK。**陽線（売りは陰線）の確定**で入る。きれいなラインが引けないときは入らない |
| 損切り | 200EMA タッチ後の押し安値（売りは戻り高値） |
| 利確 | **N計算値**。A→B（最後の上昇波の起点→終点）の値幅を、押し目の起点 C から伸ばした所 |

### 見送りのルール

- リスクリワードが **1:1 以下** → 見送り
- リスクリワードが **1:3 以上** → 見送り（波形やラインが不自然なことが多いため）
- 利確目標が **直近の高値（売りは安値）を超えない** → 見送り
- AB が **高値（安値）をきれいに更新していない** → 慎重に（ツールでは見送り扱い。設定でOFFにできます）

```
買いの例

   B ─────────────────────────────── ← 直近高値（TP はこれより上であること）
  / \      ＼ 斜めライン
 /   \       ＼  /        ★BUY（陽線でライン抜け）
A     \        ＼/
       \  ●200EMAタッチ
        C（損切り）
                       TP = C + (B − A)
```

## ツールがやること

1. 20EMA（青）と 200EMA（緑）を表示し、方向を判定
2. 200EMA にタッチしたら小さな丸を表示し、その時点の A・B を自動で決める
   - **B** = 前回のセットアップ（またはクロス）以降の最高値（売りは最安値）
   - **A** = B の直前のスイング安値（売りは高値）＝「最後の上昇波の起点」
3. タッチ後、スイング高値（売りは安値）2 点で斜めラインを引き、**途中で一度も終値で抜けていない**ラインを陽線で抜けたらブレイクと判定（ダブルボトム/トップも同様）
4. ブレイクしたら TP・SL・RR を計算し、
   - ルールを満たせば **BUY / SELL**（TP・SL ライン、RR、A・B を表示）
   - 満たさなければ **「見送り」と理由** を表示

## TradingView への入れ方

1. TradingView でチャートを開き、画面下の **「Pine エディタ」** をクリック
2. 中身をすべて消して、[`ab_signal.pine`](./ab_signal.pine) の内容を丸ごと貼り付ける
3. **「保存」** → **「チャートに追加」**
4. 動画と同じ条件で試すなら **ゴールド（XAUUSD）の 5 分足**

### アラート（通知）

チャート上部の ⏰「アラート」→ 条件で「HT EMA Signal」を選び、次から選択します。

| 選択肢 | 通知のタイミング |
|---|---|
| 買いサイン / 売りサイン | エントリー条件がそろったとき |
| 200EMAタッチ（準備） | 200EMA にタッチしたとき（チャートを見に行く合図） |
| alert() 関数呼び出しのみ | エントリー価格・SL・TP・RR 入りの通知 |

## 設定

| グループ | 項目 | 初期値 | 説明 |
|---|---|---|---|
| 移動平均線 | 短期 / 長期 EMA | 20 / 200 | 動画どおり |
| スイング検出 | 左 / 右バー数 | 4 / 2 | 斜めラインや A を探すための山・谷の検出感度。大きくすると大きな波だけを拾う |
| エントリー | 斜めライン / ダブルボトム・トップ | ON / ON | どちらのブレイクを使うか |
| エントリー | 許容差（ATR×） | 0.5 | ダブルボトム/トップの 2 つの底（天井）の高さの差がどこまでなら同じとみなすか |
| エントリー | 陽線（陰線）確定のみ | ON | 動画どおり |
| エントリー | 最大待機バー数 | 150 | 200EMA タッチからこの本数以内にブレイクしなければ取り消し |
| 見送り | RR 下限 / 上限 | 1.0 / 3.0 | 動画どおり |
| 見送り | 直近高値チェック / 高値更新チェック | ON / ON | 動画どおり |

## 注意

- **ラインの「きれいさ」や AB の選び方は、動画では裁量で判断しています。** このツールは「スイング 2 点を結び、途中で終値が抜けていないライン」「B の直前のスイング」という機械的なルールで近似しているため、動画と違う場面でサインが出たり、出なかったりします。
- 動画でも「インジケーターを機械的に使うだけでは安定しない」と話しています。サインは **エントリー候補の通知** として使い、最後はチャートを見て判断するのがおすすめです。
- サインは足の確定後に出るので、あとから消えることはありません。
- 勝率 92% は動画の検証結果です。このツールで同じ結果になるかは確認していません。まずは過去チャートでサインを見比べてから、少ないロットで試してください。投資判断はご自身の責任でお願いします。
