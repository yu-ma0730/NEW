## 1. 手法を3行で

1. **1時間足**の MACD(12,26,9) がクロスしたら合図
2. **ローソク足**が「安値切り上げ（買い）／高値切り下げ（売り）」になっているか確認
3. **4時間足と日足**の MACD ラインも同じ方向に動いていればエントリー

決済は **利確 +50pips / 損切 −30pips**（記事では利確 40〜70pips、チャートを見られないときは TP50/SL30 固定でもよいと書かれています）。

## 2. 条件の一覧（記事の文章 → ツールでの判定）

| | 記事の条件 | ツールの判定方法 |
|---|---|---|
| 買い ① | 1時間足で MACD がシグナルを下から上にクロス（ゴールデンクロス） | MACDライン > シグナル になった足から **3本以内**（設定変更可）で、今もMACD > シグナル |
| 買い ② | 陽線＋安値切り上げ（直近2本を比較） | 確定した足が **陽線** かつ **安値 > 1本前の安値** |
| 買い ③ | 日足・4時間足も MACD が上向き（明らかに上昇していればOK） | 確定済みの4時間足・日足で **MACDラインが1本前より上** |
| 売り ① | 1時間足で MACD がデッドクロス | 買い①の逆 |
| 売り ② | 高値切り下げをしているローソク足 | 確定した足の **高値 < 1本前の高値**（陰線は記事に書かれていないので初期設定では不要） |
| 売り ③ | 複数時間足で MACD が下向き | 4時間足・日足の MACDラインが1本前より下 |
| 利確 | +40〜70pips（直近高値が目安） | 初期値 **50pips**（ラインを表示） |
| 損切 | −30pips | 初期値 **30pips**（ラインを表示） |

### ツール側で決めた解釈（記事にはっきり書かれていない部分）

- 「クロス」と「ローソク足の形」が同じ足でなくてもよいように、クロス後 3 本まで待ちます（`InpCrossLookback`、1 にするとクロスと同じ足のみ）。
- 「明らかに上昇」は数値の基準がないため、「MACDラインが1本前より高い」で判定します（`InpSlopeBars` を増やすとより長い期間で比べます）。
- 判定は **確定した足だけ** を使います。上位足（4H・日足）もその時点で確定していた足を使うので、過去のサインが後から消えたり出たりしません（リペイントしない設計）。
- 記事の「直近高値を目安に利確」「押し目を割ったら損切」は人の判断が必要なので、ツールでは固定 pips だけを表示します。

## 3. インストール

1. MT5 を開き、メニュー **ファイル → データフォルダを開く**
2. `MQL5/Indicators/` に `MACD_MTF_Signal.mq5` をコピー
3. MT5 の **ナビゲーター** で「インジケーター」を右クリック → **更新**（もしくは MetaEditor で開いて **コンパイル(F7)**）
4. 通貨ペアの **1時間足(H1)チャート** にドラッグ＆ドロップ

> H1 以外のチャートに入れると「1時間足(H1)チャートに適用してください」と表示され、何もしません。

## 4. 画面の見方

- **青い▲**: 買いサイン（ローソク足の下）
- **赤い▼**: 売りサイン（ローソク足の上）
- **点線**: 最新サインの エントリー目安（灰）／TP（緑）／SL（赤）
- **左上の表示**: 直近の確定足で ①②③ がそれぞれどうなっているか

サインは足が確定した時点（次の足が始まった時点）で出ます。エントリー目安はサイン足の終値ですが、実際の約定は次の足の始値＋スプレッドになります。

## 5. 主な設定

| 設定 | 初期値 | 内容 |
|---|---|---|
| InpFastEMA / InpSlowEMA / InpSignalSMA | 12 / 26 / 9 | MACD のパラメータ |
| InpCrossLookback | 3 | クロス後にローソク足条件を待つ本数 |
| InpSlopeBars | 1 | 上位足 MACD の向きを何本前と比べるか |
| InpUseH4 / InpUseD1 | true / true | 4時間足・日足の条件を使うか |
| InpBuyNeedBullish | true | 買いで陽線を必須にする |
| InpSellNeedBearish | false | 売りで陰線を必須にする |
| InpTPPips / InpSLPips | 50 / 30 | 利確・損切の幅 |
| InpPipSize | 0 | 1pip の値幅。0 なら自動（小数3桁/5桁の通貨は 10point）。**ゴールドや指数では手動で設定**してください（例: XAUUSD を 1pip=0.1 とするなら 0.1） |
| InpAlert / InpPush / InpSound | true / false / false | 通知方法。プッシュ通知は MT5 の **ツール → オプション → 通知** でスマホの MetaQuotes ID を設定したときのみ届きます |

## 6. 注意点

- 日足の区切りは FX 会社のサーバー時間で決まるので、会社によって日足 MACD の値が少し違います。
- スプレッドや約定のズレは考えていません。
- このツールは **注文を出しません**（サイン表示と通知のみ）。
- 開発環境に MetaEditor がないため、**まだ実際にコンパイル・動作確認をしていません**。コンパイルエラーが出たら、エラーメッセージを教えてください。
