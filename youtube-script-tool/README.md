# 🎬 YouTube台本メーカー

登場人物・ジャンル・動画の時間を選ぶだけで、YouTube台本の **構成表・台本テンプレート・AI用プロンプト** を作るツールです。
クラウドワークス等の台本執筆案件と、自分のチャンネル用（オリジナル）の両方に対応しています。

## できること

| 機能 | 内容 |
|---|---|
| 用途の切り替え | 「クラウドワークス等の依頼」／「オリジナル」 |
| 登場人物 | **語り手**（解説する）と **受け手**（質問・リアクション）をそれぞれ選択。ゆっくり霊夢・魔理沙、ずんだもん、四国めたん、先生・生徒など。名前と口調は自由に変更可。受け手「なし」で1人語り |
| ジャンル | 雑学、歴史、ビジネス・お金、ランキング、レビュー、2ch・スカッと系、ホラーなど。ジャンルに合った構成（例：スカッと系は「事件発生→エスカレート→反撃」）になる |
| 動画の時間 | 「〜分ぐらい」で指定 → 目標文字数とパートごとの時間・文字数を自動計算 |
| 依頼モード | 指定文字数・マニュアルの指示・NGワードを入力可。**AI利用が許可されていない依頼では、AI生成とプロンプト作成をオフ**にする |
| オリジナルモード | チャンネル名・コンセプト・最後の呼びかけ（CTA）を反映 |
| 出力 | 構成表／書き込み用テンプレート／AI用プロンプト（コピーしてチャットに貼れる）／台本エディタ（文字数カウント・.txt保存） |
| AI生成（任意） | `ANTHROPIC_API_KEY` を設定すると、Claude で台本の下書きを生成 |

## 使い方

```bash
cd youtube-script-tool
pip install -r requirements.txt
cp .env.example .env   # AI生成を使う場合のみ、APIキーを記入
uvicorn main:app --reload
```

ブラウザで http://localhost:8000 を開きます。

## テスト

```bash
pip install pytest httpx
pytest -q
```

## ファイル構成

```
youtube-script-tool/
├── main.py              # FastAPI（API・画面の配信）
├── script_builder.py    # 構成・テンプレート・プロンプトの組み立て（キャラ・ジャンルの選択肢もここ）
├── static/index.html    # 画面
├── test_app.py          # テスト
├── requirements.txt
├── vercel.json
└── .env.example
```

キャラクターやジャンルを増やしたいときは、`script_builder.py` の `CHARACTERS` / `GENRES` / `STRUCTURES` に追記してください。

## 注意

- 1分あたりの文字数（掛け合い330字・1人語り300字）は目安です。読み上げソフトの速度に合わせて `CHARS_PER_MINUTE` を調整してください。
- AIの下書きは事実誤りを含むことがあります。【要確認】の箇所を中心に、必ず見直してから使ってください。
