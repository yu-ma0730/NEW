# ケアきろく（障がい者グループホーム 記録・帳票・チェック システム）試作版

紙の記録をタブレットで入力し、AIが文章の原案をつくり、管理者が承認し、Excel帳票や請求前チェックまでをつなぐWebシステムです。
**今の状態は「動く試作版（デモデータ入り）」です。** 実データでの運用には、`docs/仕様書.md` の「本番までに必要なこと」を行う必要があります。

## 起動のしかた（3ステップ）

1. Python 3.9 以上が入ったPCを用意する（追加のインストールは不要）
2. このフォルダで次を実行する
   ```
   python3 server.py
   ```
3. ブラウザで http://localhost:8000 を開く

| ログインID | 役割 | パスワード |
|---|---|---|
| manager | 管理者 | demo1234 |
| sabikan | サービス管理責任者 | demo1234 |
| staff1 / staff2 | 職員 | demo1234 |

- 事業所内のタブレットから使う：`python3 server.py --host 0.0.0.0`（暗号化のため本番では必ずHTTPS：`--cert cert.pem --key key.pem`）
- データは `data/carekiroku.db` に保存されます。最初からやり直すときはこのファイルを消して起動し直します（**デモ用のみ**）。

## できること（依頼のステップ①〜⑧との対応）

| ステップ | 画面 | 内容 |
|---|---|---|
| ① 初期登録・現場入力 | 利用者・計画・職員／きろくを書く | 利用者・職員・個別支援計画の登録。記録は「①だれ → ②なにを → ③入力」の3ステップ。ボタン選択・定型文・音声入力 |
| ② AI記録作成・申し送り | 文章にする／申し送り | 入力内容**だけ**で原案を作成（推測で事実を足さない）。足りない項目・危険な言葉（転倒・発熱など）を確認事項として表示。申し送りを利用者別に整理 |
| ③ データ保存・帳票連携 | さがす／Excel(CSV)出力 | SQLiteに一元保存。検索。記録一覧・稼働表・勤務実績をExcelで開けるCSVで出力 |
| ④ 請求前・勤怠チェック | 請求前チェック | 記録もれ、稼働表の未入力・矛盾、シフトと打刻のずれ、未承認、計画期限を一覧化。「直す」リンク→「もう一度チェック」 |
| ⑤ 事故・ヒヤリ分析 | 事故・ヒヤリ | 報告、似た過去事例と対策の検索、分類・場所・時間帯・利用者別の集計、会議資料の自動作成 |
| ⑥ 報告書・行政書類 | 書類をつくる | 事故報告書・改善会議資料・議事録・研修記録・モニタリング記録の原案。記入もれを赤で表示。印刷/PDF・Word(.doc)保存 |
| ⑦ 業務チェック・通知 | 毎日のチェック／お知らせ／期限 | 服薬・感染症・防災・事故防止のチェック表。未実施、服薬記録もれ、期限の近い提出物、差し戻しをホームに通知 |
| ⑧ 承認・履歴 | 確認・承認／操作の履歴 | サビ管・管理者が承認／理由つき差し戻し。入力・修正・承認・出力をすべて「だれが・いつ・前→後」で記録 |

## テスト

```
python3 -m unittest discover -s tests -v
```
結果は `docs/テスト結果.md`。

## フォルダ構成

```
server.py        サーバー（API・権限チェック・画面の配信）
app/db.py        データベースの形とデモデータ
app/ai.py        記録の原案づくり・申し送り整理・入力項目の定義
app/checks.py    請求前・勤怠・実績チェック
app/reports.py   事故分析・書類の原案
static/          画面（index.html / app.js / style.css）
tests/           自動テスト
docs/            仕様書・操作手順書・テスト結果
```
