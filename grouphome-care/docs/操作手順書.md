# 操作手順書（職員・管理者むけ）

## 1. ログイン
1. タブレットでブラウザを開き、事業所で決められたアドレスを開く
2. ID とパスワードを入れて「ログイン」
3. 使い終わったら右上の「ログアウト」（共有タブレットでは必ず）

## 2. 出勤・退勤
ホームの「🟢 出勤」「🔴 退勤」を押すだけです。夜勤明けの退勤は前日の出勤に自動でつながります。

## 3. 記録を書く（いちばん使う操作）
1. ホームの「✏️ きろくを書く」
2. **① だれ？** 利用者の名前を押す（事業所全体のことは「事業所全体」）
3. **② なにを？** バイタル・食事・服薬・排泄・ケース記録・申し送りから選ぶ（✓ は今日もう書いたもの）
4. **③ 入力する** ボタンを押して選ぶ。体温は「36.5」などのボタンでも入る
5. メモは手で書くか、🎤 を押して話す（終わったら ■）
6. 「✨ 文章にする」→ 文章ができる。⚠️ の確認事項を読んで、必要なら文章を直す
7. 「💾 保存して提出」→ サビ管・管理者が確認します

> 文章は、あなたが入力した内容だけでつくられます。事実とちがうところは必ず直してください。

## 4. 申し送りを見る
「📣 申し送り」：利用者ごとに、前の勤務からの連絡が並びます。「大事」は赤い印。下に利用者の特記事項も出ます。

## 5. 差し戻されたとき
ホームに「差し戻された記録があります」と出ます → 押す → 記録を開き、理由を読んで直し「直して保存」。

## 6. 事故・ヒヤリハット
「⚠️ 事故・ヒヤリ」→「＋ 報告する」。分類・場所をボタンで選び、何があったかを書く（話してもOK）。
「🔎 似ている過去の事例を見る」で、前の対策を参考にできます。

## 7. 毎日のチェック
「✅ 毎日のチェック」で、終わった項目の「まだ」を押すと「できた」になります。

## 8. 管理者・サービス管理責任者の操作
| やりたいこと | 画面 |
|---|---|
| 記録・事故報告・書類・計画を承認／差し戻し | 🖊️ 確認・承認（まとめて承認できます。差し戻しは理由が必須） |
| 請求の前に、もれや不一致を調べる | 🧮 請求前チェック →「チェックする」→ 各行の「直す」→「もう一度チェック」 |
| 在宅・外泊・入院を付ける | 🗓️ 稼働表（マスを押すたびに切り替わる） |
| Excelに出す | 請求前チェック／稼働表の「Excel(CSV)で出す」 |
| シフト登録・打刻修正（管理者） | ⏰ シフト・勤怠 |
| 報告書・議事録・研修記録・モニタリング | 📄 書類をつくる → 種類 → 「原案をつくる」→ 赤い欄を書く → 保存／印刷 |
| 利用者・計画・職員・チェック項目の登録 | 👥 利用者・計画・職員 |
| だれが何をしたか見る | 📜 操作の履歴 |

## 9. 困ったとき
- 🎤 が使えない：ブラウザが音声入力に対応していません。キーボードのマイクボタンを使ってください
- 「ログインしてください」と出た：12時間たつと自動でログアウトします。もう一度ログイン
- 5回まちがえると5分間ログインできません
